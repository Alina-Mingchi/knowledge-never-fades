# Knowledge Weaver

I would like to build a project that is a webUI, having 3 parts. The project name is Knowledge Never Fades. It should ask the user to select the language, which will communicate also to the ElevenLab Agents what language to use

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://knowledge-never-fades.lovable.app
