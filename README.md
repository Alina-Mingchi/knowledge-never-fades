# Knowledge Never Fades

This is a project that is a webUI, having 3 modules. It first ask the user to select the language, which will communicate also to the ElevenLab Agents what language to use

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://knowledge-never-fades.lovable.app

# Motivation

Every company has experts whose knowledge lives only in their heads — and it walks out the door the day they leave. With Knowledge Never Fades, we capture that expertise while they work.

Our voice apprentice watches the expert's screen, stays quiet while they're busy, and at natural pauses asks the questions that matter: why this invoice first? why this cost center? It captures not just the steps, but the reasons and the guardrails — like "never save anything over $10,000 without asking the manager."

Those moments become a clickable Work Map: every step linked to the exact screen moment and the expert's own words, confirmed through a spoken teach-back.

Then comes the payoff: a patient AI tutor coaches the new hire on their own screen — on their real case. It stops them before they break the expert's guardrail, replays the expert's reasoning, and proves mastery.

Experts stay in flow. New hires ramp in hours, not months. Knowledge — never fades.
